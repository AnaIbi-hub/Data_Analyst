# West Bank Settlements — Projecte Final Data Analytics

Anàlisi exploratòria de l'evolució demogràfica, territorial i de l'impacte humanitari
dels assentaments israelians a Cisjordània (1967–2026), amb especial atenció a
l'acceleració posterior al 7 d'octubre de 2023.

## Estructura

- **Datasets/** — Fonts de dades originals (Peace Now, B'Tselem, Jewish Virtual Library, OCHA).
- **Notebooks/** — Pipeline de neteja i anàlisi en Python (8 notebooks, `01` a `08`, executar en ordre).
- **Outputs_Notebooks_PowerBi/** — Els 7 conjunts de dades ja processats que alimenten el dashboard de Power BI, més el diccionari de dades (`powerbi_data_dictionary.md`).
- **West_Bank_Settlements.pbix** — Dashboard de Power BI (6 pàgines).
- **Informe_Final.pdf** — Informe científic del projecte (màxim 4 pàgines).
- **West_Bank_Settlements_PowerBI.pdf** — Exportació del dashboard a PDF.
- **DAX_Formulas.md** — Totes les mesures DAX utilitzades al model.
- **Presentacio_Defensa.pptx** — Presentació per a la defensa oral.
